# KOGANE 

An AI companion inspired by **Kogane** from *Jujutsu Kaisen*.

KOGANE is being built from scratch in Python with the long-term goal of becoming an intelligent desktop assistant and eventually robotic companion capable of conversation, memory, computer vision, and autonomous interaction.

---

## Current Version

v0.1.0 - Initialization

### Current Features

- Project structure created
- Python environment configured
- Basic terminal interaction
- Development docmentation
